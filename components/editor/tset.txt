renderHighlight
macroHighlight

both of these do different jobs

1. renderHighlight does:

get flags & variants from robot-is-chill:

a = ((?:--|-)(?:[^- &:;>]+))(=)?([^ &:;>]+)?
b = ([:;])([^ &:;>]+)

a and b does check if name is valid with startsWith

b will do extra work because it has to highlight only the name, not the value

(
    old uses :name(values?)?+ / :name(values1?)(values2?)...?+ while new uses :namevalue?+ and values are separated by /
)

then a and b will highlight the values only on values except "/"s.

2. macroHighlight does:

do bracketDepths + check escape state

highlight [], [/anything] while when doing [/any[thing]], it will ignore [thing] when bracketdepth is > 1

highlight brackets along with bracket data for highlight brackets (outline) when inside or on caret

highlight macro names when [name] and values when [name/arg/arg] highlights arg as macro value

also highlight value escape because i made it to make it easier to determine escaped values and unescaped values
