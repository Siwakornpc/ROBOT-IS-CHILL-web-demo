When you enter this web first time, it will automatically redirect you to `/macrosia`.

Inside that page, it will introduce you with a code editor, and an output. It will automatically updates each time you are typing the macroscript. The 'run-code' button is provided if the script needs re-running.

On the left side, there is a few pages:
- Macrosia
- Render
- Search
and the bottom most:
- Settings

This repository is a port of [ROBOT IS CHILL](https://github.com/ROBOT-IS-CHILL/robot-is-chill) which will include an image rendering, variant mutations and flags, along with Macroscript. Which, will be put inside as a web demo with a VSCode and regex101-like UI/UX, style and themes.

We are a small team, and this would not be developing as fast as it is.
